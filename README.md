# Foxing Around
## Play it here -- https://arontheb.itch.io/foxing-around
### This is a simple platformer game made in Godot for Hackclub Jumpstart
Your goal is to find all 7 diamonds and take them to your house
#### Controls:
Left- A, Left Arrow Key

Right- D,  Right Arrow Key

Jump- W, Space, Top Arrow Key
